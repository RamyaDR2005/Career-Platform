1. Introduction
1.1 Purpose

The AI Career Intelligence Platform is an AI-powered employability ecosystem designed to assist engineering students throughout their placement journey. The platform leverages IBM watsonx.ai and Granite foundation models to analyze resumes, identify skill gaps, recommend learning paths, conduct AI-driven mock interviews, and intelligently match students with suitable job opportunities.

The system also provides dedicated portals for Placement Officers, Recruiters, Faculty Mentors, and Administrators, enabling end-to-end automation of campus recruitment activities.

1.2 Scope

The platform provides

AI Resume Analysis
AI Skill Gap Detection
Personalized Learning Roadmap
Mock Interviews
Placement Readiness Score
Recruiter Candidate Ranking
Placement Analytics
Resume Management
Company Management
Student Progress Tracking
Notification System

The application will be accessible through any modern web browser and deployed on cloud infrastructure.

1.3 Objectives
Improve placement readiness.
Reduce manual effort for placement officers.
Help recruiters shortlist candidates efficiently.
Provide personalized AI career guidance.
Automate placement activities using intelligent agents.
2. Overall Description

The application is a centralized web platform connecting four primary stakeholders:

Students
Placement Officers
Recruiters
Administrators

The platform continuously analyzes student data using IBM AI services and provides personalized career recommendations.

3. Product Perspective

The platform functions as an intelligent layer above the traditional placement process.

Instead of manually reviewing resumes and tracking student progress, AI agents automate analysis, recommendations, and candidate ranking.

It acts as an AI Career Operating System for engineering institutions.

Database Design – ER diagram, normalized schema, and Prisma models.
UI/UX Design – Information architecture, wireframes, design system, and high-fidelity screens.
API Specification – REST endpoints (or Route Handlers), request/response schemas, validation rules, and authentication flow.
